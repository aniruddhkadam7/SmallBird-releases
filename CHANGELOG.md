# Changelog

All notable changes to the Smallbird desktop app (Windows and Mac) are documented here, alongside the
[GitHub Releases](https://github.com/aniruddhkadam7/SmallBird-releases/releases) that ship them.
Each release includes a signed installer and an auto-update manifest; the app updates itself
automatically.

## [0.1.9] - 2026-09-04

- Added a dashboard sign-in handoff from the desktop app's post-interview screen: ending an
  interview now offers an "Open Dashboard" button that signs you into the website automatically.
- Email-code sign-up now also collects a full name.

## [0.1.8] - 2026-09-03

- Redesigned the Interview Mode overlay with a cleaner three-tier layout and real button icons.
- Added **Analyze Screen**: captures your primary screen and asks the AI to identify or work
  through whatever's shown (a coding problem, a diagram, written questions), alongside your
  question.
- Answers are now more concise, and code responses are syntax-highlighted.

## [0.1.7] - 2026-09-03

- Interviews completed while signed in now show up under "My Interviews" on the website.

## [0.1.6] - 2026-09-03

- Fixed the uninstaller icon.
- Account and Settings now show the real running app version.
- Added a Smallbird trademark notice.

## [0.1.5] - 2026-09-03

- Fixed Ask AI capturing a late-arriving partial transcript into the next question.
- Restyled compact header buttons with a flatter, higher-contrast look.

## [0.1.4] - 2026-09-03

- Update progress now shows as a small indicator in the header instead of taking over the whole
  window.

---

v0.1.4 is the earliest release published to this repository. See the full
[release history](https://github.com/aniruddhkadam7/SmallBird-releases/releases) for signed
installers and auto-update manifests for each version above.
